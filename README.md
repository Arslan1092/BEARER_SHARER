# BEARER SHARER — Professional Full-Stack Website

## Included
- Node.js + Express backend
- Built-in Node SQLite database (`node:sqlite`)
- Secure admin setup/login with scrypt password hashing and HttpOnly sessions
- CSRF protection for admin mutations
- Helmet security headers and rate limiting
- Contact/enquiry storage
- Responsive premium frontend
- Animated 24/7 BEARER SHARER ticker
- Prominent Trading section
- Supplied BEARER SHARER, YouTube and Amazon image assets
- Platform links for YouTube, TikTok, Amazon, eBay and LinkedIn

## Requirements
- Node.js 24+
- Windows 11 works directly

## Run
```bash
npm install
npm start
```

Open:
- Website: http://127.0.0.1:3000
- Admin: http://127.0.0.1:3000/admin

The first visit to `/admin` creates the administrator account. Use a strong password (12+ characters). There is no hard-coded admin password.
