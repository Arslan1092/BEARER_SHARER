BEARER SHARER — PROJECT HANDOFF / CONTINUATION CODE

PROJECT: BEARER SHARER
GOAL: Professional, secure, responsive full-stack website for BEARER SHARER.

CURRENT STATE:
- Backend: Node.js + Express.
- Database: Node 24 built-in SQLite (`node:sqlite`).
- Security: Helmet, rate limiting, scrypt password hashing, HttpOnly SameSite sessions, CSRF protection for admin changes.
- Frontend: premium responsive single-page website with animations.
- Admin: /admin with one-time secure setup, login, enquiry management and status updates.
- Contact form: saves enquiries to SQLite.
- Animated strip: BEARER SHARER / VISIBILITY / TRAFFIC / VIEWS / SALES, continuously moving.
- Main Trading section: intentionally prominent.
- Trading URL: https://www.bearers-trade.quest/#/register
